# منصة "اسأل كتابك" — توليد أسئلة من أي ملف بالذكاء الاصطناعي

منصة عربية بواجهة RTL: المستخدم يرفع كتاب / ملف / صور، الذكاء الاصطناعي يقرأ المحتوى بالتفصيل، ثم يولّد أسئلة بأنواع مختلفة، ويمكن حلّها إلكترونيًا مع تصحيح فوري أو تصديرها PDF / Word.

## تنبيه مهم أولاً
مفتاح الـ API الذي كتبته في المحادثة أصبح مكشوفًا — الرجاء إلغاؤه من لوحة المزوّد وإنشاء مفتاح جديد. المفتاح الجديد يُدخل عبر نموذج الأسرار الآمن (لا يُكتب في الكود أبدًا).

## تجربة المستخدم

1. **الصفحة الرئيسية** — تعريف بالمنصة، دعوة لتسجيل الدخول/إنشاء حساب، شرح الخطوات الثلاث.
2. **تسجيل الدخول / إنشاء حساب** — بريد + كلمة مرور.
3. **لوحة الحساب** — قائمة الملفات المرفوعة وكل الاختبارات المولّدة منها، مع النتائج السابقة.
4. **رفع مستند** — PDF, Word, صور (JPG/PNG), نص. شريط تقدّم وحالة "جاري القراءة".
5. **إعدادات التوليد** — عدد الأسئلة، مستوى الصعوبة، اللغة، ونسبة كل نوع:
   - اختيار من متعدد
   - صح / خطأ
   - إجابة قصيرة / مقالية
   - إكمال الفراغ
   ويمكن أيضًا كتابة طلب حر ("ركّز على الفصل الثالث").
6. **صفحة الاختبار** — عرض الأسئلة، تعديل/حذف أي سؤال، إعادة توليد سؤال واحد.
7. **الحل الإلكتروني** — عرض سؤال بسؤال أو الكل، مؤقّت اختياري، تصحيح فوري بعد التسليم: الدرجة، الإجابة الصحيحة، وشرح لكل سؤال. الأسئلة المقالية تُصحّح بالذكاء الاصطناعي مع تعليق.
8. **التصدير** — PDF و Word (.docx) بنسختين: ورقة الأسئلة، وورقة الإجابات النموذجية.

## الهوية البصرية
اتجاه عربي RTL بخط عربي واضح (مثل IBM Plex Sans Arabic)، لوحة ألوان تعليمية هادئة (أزرق عميق + أخضر زمردي كلون تمييز) على خلفية فاتحة، بطاقات ناعمة الحواف. كل الألوان كرموز تصميم في نظام التصميم، ودعم الوضع الليلي.

## التفاصيل التقنية

- **الخلفية**: Lovable Cloud (قاعدة بيانات + مصادقة + تخزين ملفات).
- **الجداول**: `profiles`، `documents` (اسم، نوع، مسار في التخزين، النص المستخرج، حالة المعالجة)، `quizzes` (إعدادات التوليد)، `questions` (نوع، نص، خيارات، الإجابة الصحيحة، الشرح)، `attempts` + `answers` (محاولات الحل والدرجات). كل جدول مع GRANTs وسياسات RLS تقصر البيانات على `auth.uid()`.
- **التخزين**: bucket خاص `documents` مع سياسات لكل مستخدم على مجلّده.
- **الذكاء الاصطناعي**: يُنفَّذ داخل server functions فقط (المفتاح لا يصل للمتصفح). المفتاح يُخزَّن كسر باسم واضح ويُقرأ من `process.env` داخل الـ handler. القراءة تشمل PDF/Word/الصور (OCR بصرية) وتُستخرج كنص يُخزَّن مرة واحدة، ثم تُبنى الأسئلة بمخرجات منظّمة (JSON schema) لضمان أنواع الأسئلة والإجابات والشروح.
- **الملفات الطويلة**: تقسيم النص إلى مقاطع وتوليد الأسئلة على دفعات، مع بثّ (streaming) لتجنّب انتهاء المهلة.
- **التصدير**: توليد PDF و .docx في المتصفح عبر مكتبات عمل جاهزة مع دعم العربية RTL.
- **الأخطاء**: رسائل واضحة للمستخدم عند فشل مزوّد الذكاء الاصطناعي أو تجاوز الحدود، مع الحفاظ على مدخلاته.

## ترتيب التنفيذ

1. تفعيل Lovable Cloud + المصادقة + الجداول والتخزين والسياسات.
2. نظام التصميم العربي RTL + الصفحة الرئيسية + صفحة الدخول.
3. الرفع والاستخراج والقراءة بالذكاء الاصطناعي.
4. توليد الأسئلة + صفحة تحرير الاختبار.
5. الحل الإلكتروني والتصحيح الفوري والنتائج.
6. تصدير PDF و Word.
7. لوحة الحساب والسجل، ثم مراجعة أمنية نهائية.

## يحتاج منك
- تفعيل Lovable Cloud (Connectors → Lovable Cloud → Tool Permissions).
- مفتاح API جديد بعد إلغاء القديم، سأطلبه عبر نموذج آمن في وقته.
